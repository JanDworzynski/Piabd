# Komendy mysql shell:
Jest to ściąga z komendami MySql na wszelki wypadek jakby coś wypadło z głowy!!!
## Połączenie przez CMD z MYSQL:
```text
mysql -u (uzytkownik) -p (hasło)
```

## Pokazanie tabeli w bazie danych
```text
show tables;
```
<p align="left">
   <img src="https://github.com/JanDworzynski/Piabd/blob/main/zrzuty/pokazanietabeli.png?raw=true" alt=skills" /p>
</p>   
1.Logowanie: mysql -uroot -p

2.Wybór bazy: use nazwabazy;

3.Tworzenie bazy: create database nazwabazy;

4.Tworzenie tabeli: create table nazwatabeli;

5.Pokazywanie zawartości tabeli: describe nazwatebeli;
